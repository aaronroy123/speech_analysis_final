Multimodal Emotion Recognition System - How to Run
==================================================

This repository contains a full end-to-end pipeline for a Multimodal Emotion Recognition system built using the Toronto emotional speech set (TESS) dataset.

The system combines two modalities using Late Fusion:
1. Speech Pipeline: Mel-Spectrograms + Bidirectional LSTM (BiLSTM).
2. Text Pipeline: Transcripts + Frozen BERT-base embeddings.

Fusion accuracy: 99.38% overall accuracy.

---

GETTING STARTED
---------------

1. Prerequisites:
   - Python 3.8+
   - PyTorch-compatible environment

2. Clone the Repository:
   git clone https://github.com/aaronroy123/speech_analysis_final.git
   cd speech_analysis_final

3. Setup Virtual Environment & Dependencies:
   # Create virtual environment
   python -m venv .venv

   # Activate virtual environment
   * On macOS/Linux:          source .venv/bin/activate
   * On Windows (PowerShell): .\.venv\Scripts\Activate.ps1
   * On Windows (CMD):        .\.venv\Scripts\activate.bat

   # Install dependencies
   pip install -r requirements.txt

4. Download the Dataset:
   - Download the TESS dataset from Kaggle:
     https://www.kaggle.com/datasets/ejlocurto/tess-toronto-emotional-speech-set-data
   - Create a folder named "data" in the project root.
   - Extract the dataset so that the path matches exactly:
     data/TESS Toronto emotional speech set data/

---

RUNNING THE PROJECT
-------------------

Option A: Unified Runner (macOS/Linux)
   chmod +x run_all.sh
   ./run_all.sh

Option B: Manual Pipeline Commands (Windows/Manual)
   # 1. Speech Pipeline
   python models/speech_pipeline/train.py --data_dir "data/TESS Toronto emotional speech set data"
   python models/speech_pipeline/test.py --data_dir "data/TESS Toronto emotional speech set data"

   # 2. Text Pipeline
   python models/text_pipeline/train.py --data_dir "data/TESS Toronto emotional speech set data"
   python models/text_pipeline/test.py --data_dir "data/TESS Toronto emotional speech set data"

   # 3. Fusion Pipeline
   python models/fusion_pipeline/train.py --data_dir "data/TESS Toronto emotional speech set data"
   python models/fusion_pipeline/test.py --data_dir "data/TESS Toronto emotional speech set data"
